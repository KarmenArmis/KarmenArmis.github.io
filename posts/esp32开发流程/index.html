ESP32开发流程

April 25, 2024 · 3 分鐘 · 1419 字 · KarmenArmis

本文将讲解ESP IDF环境配置及如何在VSCode中使用ESP IDF配置多版本。

值得注意的是，不同版本的 ESP IDF对项目的影响很大。或者说，乐鑫官方并未考虑到对ESP IDF向前兼容，这会导致使用不同版本的ESP IDF编译同一工程可能会产生错误。下面是一个例子：

错误：Failed to resolve component ’esp_adc_cal’.
原因：从 IDF5.0 开始，该组件esp_adc_cal已重命名为esp_adc，请在组件的cmakelist中将…PRIV_REQUIRES esp_adc_cal)改为……PRIV_REQUIRES esp_adc)

从零开始配置ESP IDF

为了更方便的使用，我们希望之后的程序编写、调试、烧录过程都能在VSCode中以图形化的方式完成。VSCode的ESP-IDF插件是个很好的帮手。不过，其自带的ESP-IDF环境下载及配置并不友好，经常会出现Python虚拟环境安装失败、只能安装一个ESP IDF版本等众多错误。建议自行安装ESP环境。

exp-idf可以从以下官方网站下载：https://dl.espressif.com/dl/esp-idf/
请选择一个离线版本进行安装。

![](img/esp download.png)

选择一个安装路径，该下载器会自动下载并配置好环境。在结束时请勾选“将ESP-IDF工具的可执行文件注册为Windows Defender的排除项。”

接着，使用命令行，转到您安装的位置，例如：C:\Users\xxx\esp\v4.4.7\frameworks\esp-idf-v4.4.7，并执行export.bat命令，这一步是为了将ESP IDF编译所需要的工具临时地添加入PATH。

出现如下命令代表您已成功安装：

然而，在大多数情况，安装并不能顺利地进行。比如提示Python环境未安装完成等：

Checking if Python packages are up to date... ERROR: C:\Users\ThinkPad\.espressif\python_env\idf5.2_py3.12_env\Scripts\python.exe doesn't exist! Please run the install script or "idf_tools.py install-python-env" in order to create it

您可以运行install.bat来自动地安装各类依赖。确保最终提示如上所示。

如果您希望自行使用包管理工具pip来安装各种依赖，确保安装时未有开启各类网络代理服务。

之后，请安装VSCode 并下载ESP-IDF插件。如果您曾经下载过该插件并使用Express模式安装过ESP环境。请按照以下步骤卸载。

删除C:\Users\xxx\esp文件夹
删除C:\Users\xxx\.espressif文件夹
删除C:\Users\xxx\.vscode\extensions\espressif.esp-idf-extension-1.7.1文件夹

之后，重新下载ESP-IDF插件并使用Use Existing Setup来配置。如果点选该项后显示的ESP-IDF版本并非您刚才下载的版本（例如显示您曾经安装的ESP IDF版本），或者， 不显示任何版本，请执行以下操作。

在VSCode设置页面(ctrl + ,)，查找并删除以下五项配置。

最后，关闭所有文件夹并重新启动VSCode，选择Use Existing Setup，应当会显示您刚才下载的版本。

编译并烧录程序。

如果遇到以下提示：Can’t proceed with flashing, since project elf file (aWarmHost.elf) is missing from the build dir. (d:\Project\Realtime_Tempmeter\MY\Displayer\build)。
表明您为完全配置COM和ESP硬件版本

如果遇到以下提示：Partitions tables occupies 2.1MB of flash (2162688 bytes) which does not fit in configured flash size 2MB. Change the flash size in menuconfig under the ‘Serial Flasher Config’ menu.
表明分区表中factory区太小，请调整Flash Size

或者，定义分区表

并编辑以下内容

# ESP-IDF Partition Table
# Name,   Type, SubType, Offset,  Size, Flags
nvs,      data, nvs,     0x9000,  0x4000,
otadata,  data, ota,     0xd000,  0x2000,
phy_init, data, phy,     0xf000,  0x1000,
factory,  app,  factory, 0x10000,  3M,
